INSTALL

拖入应用程序，然后授权

普通用户不需要 Xcode、Swift 或源码目录。系统中已有 DSH 和 Google Chrome 即可。

  1. 01

    安装 App

    打开 Universal 2 DMG，将 DSH Computer Use 拖入“应用程序”。

  2. 02

    确认系统权限

    在设置中心授权“辅助功能”和“屏幕录制”。权限只在本机使用。

  3. 03

    安装 DSH 插件

    点击“安装”。Bundle 自动注册 Host 与工具，无需手改 YAML；随后重启 DSH Host。

打开 Releases 下载文件：DSH-Computer-Use-*-universal.dmg

Finder 启动显示设置中心；DSH 使用同一个 App 的 --agent 模式启动后台 socket。两个模式共享稳定的 bundle ID 与 TCC 身份。

PERCEPTION

AX + CDP + Vision

先取语义，必要时补 OCR；截图是验证材料，不是默认模型上下文。

INPUT

目标优先，公开回退

AX 语义动作优先，再走目标进程/窗口输入；无目标时才允许全局 HID。

PLATFORM BOUNDARY

对 macOS 限制保持诚实

Stage Manager

macOS 26 的架上窗口可能只暴露缩略图。系统会保留 AX 观察并返回明确 warning，不拉伸伪截图，也不进入已知崩溃路径。

SkyLight

后台定向输入使用私有 API，因此完整版本通过 Developer ID 直接分发，不适合 Mac App Store。符号不可用时公开回退或失败关闭。
